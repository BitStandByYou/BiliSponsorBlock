# 宿主适配：哔哩哔哩国内版 9.12.0

> 本文档是**国内版 Hook 适配的唯一事实来源**。结论基于对已安装宿主 `base.apk`
> 的静态分析（`dexdump` + `jadx --single-class`）与真机探针日志。
> 上游 Bili2233 的 `docs/APK_6.5.0_ANALYSIS.md` 只针对国际版 6.5.0，**不可直接沿用**。

## 0. 为什么不能照抄上游

上游目标是国际版 `com.bilibili.app.in` 6.5.0（versionCode 9110200），播放器栈被 R8 深度混淆：
`service.E0`、方法 `G`/`j0`/`z0`、容器接口 `tv.danmaku.biliplayerv2.f`、`mine.d`、`seek.v3.q/e`。

国内版 `tv.danmaku.bili` 9.12.0（versionCode 9120300）**不是同一代混淆产物**，播放器栈大量保留真名：

| 能力 | 上游 6.5.0 | 国内 9.12.0 |
| --- | --- | --- |
| 进度回调 | `PlayerProgressTextWidget#G(int,int)` | **`PlayerProgressTextWidget#onPlayerProgressChange(int,int)`** |
| 观察者接口 | `service.E0`（混淆） | **`service.VideoDirectorObserver`（真名）** |
| 注册观察者 | `PlayDirectorServiceV3#j0(E0)` | **`PlayDirectorServiceV3#addVideoDirectorObserver(o)`** |
| 播放容器 | 接口 `tv.danmaku.biliplayerv2.f` | **`tv.danmaku.biliplayerv2.PlayerContainer`** |
| 取 Context | 容器 `t()` | **容器 `getContext()`** |
| seek | core `o(int,boolean)` | **core `seekTo(int,boolean)`** |
| 当前条目 | `service.D()` → `Video$e#z()` | **`getCurrentPlayableParams()` → `Video$PlayableParams#getDanmakuResolveParams()`** |
| 面板适配器 | `com.bilibili.app.gemini.ui.f`（RecyclerView 行） | **同名类实为 `IntroAdapter`（详情页）**，面板已改 Compose |

教训：**同名短类名在新版本里可能是完全不同的类**（`gemini.ui.f`），必须按结构/真名核对，不能靠名字猜。

## 2. DexKit 兜底（被混淆的锚点）

以下锚点是**混淆短名**，随版本重排：`seek.v3.g` / `seek.v3.f`、`mine.d`。

实现见 `host/DexKitResolver.kt`：

- **真名/候选名优先**：候选全部存在时**完全跳过** DexKit（零开销，`DexKitBridge.create` 很贵）。
- 候选落空时才创建桥，按**结构条件**定位：
  - seekTrack：包前缀 `com.bilibili.playerbizcommonv2.widget.seek.v3.` + 父类 `android.graphics.drawable.Drawable`
    + 声明 `draw(android.graphics.Canvas)`。
  - mineAdapter：包前缀 `tv.danmaku.bili.ui.main2.mine.` + 父类 `RecyclerView$Adapter` + 字段类型 `java.util.List`。
- 结果写入 `ResolvedTargets`，供 Hook 安装读取；桥用 `.use {}` 自动释放。

## 3. 未适配：播放器「更多」面板

上游在播放器右上角「⋯ → 更多」里注入一行「空降助手」。国内 9.12.0 该面板：

- 宿主为 `com.bilibili.ship.theseus.united.page.toolbar.MenuService`；
- 内容已改为 **Compose**（`com.bilibili.playerbizcommonv2.widget.setting.PlayerSettingComposeKt`、
  `PlayerSettingFunctionWidget2`），不再是 RecyclerView + `gemini.ui.f`。

因此上游的「往 adapter 的 List 里 append 一个 `i` 代理行」方案**不适用**。
当前状态：`HostTargets.MORE_PANEL_SUPPORTED = false`，安装时打印 `hook skip: morePanel`，
播放器内暂无入口；设置弹窗仍提供全部开关与统计。

后续若要补回，需要研究 Compose 侧的注入点（例如面板数据列表的构建函数），属独立课题。

## 4. 其它国内版差异

- 模块日志 TAG：`BiliSB`。
- 宿主数据目录：`/data/data/tv.danmaku.bili`（JSON 镜像 / 统计文件）。
- 模块**无桌面图标**：设置 UI 在宿主进程内以 Dialog 呈现（`SponsorBlockSettingDialog`），
  不依赖 `LauncherActivity`，也不需要模块自身进程常驻。
